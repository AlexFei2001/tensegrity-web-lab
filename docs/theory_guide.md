# 独立理论章节

导航第五项 Theory / 理论 / Teoria；Optimization 标题下提供直达入口。原先所有页面下方的卡片已移入理论章的术语部分。

全称在选择框、开头三张卡片、对照表与各小节重复呈现：GA / Genetic Algorithm / 遗传算法 / Algoritmo genetico；PSO / Particle Swarm Optimization / 粒子群优化算法 / Ottimizzazione a sciame di particelle；SA / Simulated Annealing / 模拟退火算法 / Ricottura simulata。下拉选项的内部值仍为GA/PSO/SA，翻译不会破坏算法选择。

章节结构：

1. 共同最小化目标、候选z、评价值f、步t、索引i、clip与均匀随机数；明确Rastrigin数学变量与结构变量θ/P的区别。
2. GA、PSO、SA的候选数量、更新机制、记忆和探索方式对照。
3. GA步骤图及本实现的父代选择、二维交叉、单坐标变异公式。参数N=12、父代池较优半数、E=1、变异幅度s=0.10；不把未设置的p_c/p_m伪装成可调控件。
4. PSO速度与位置更新，解释w、c₁、c₂、r₁/r₂、pbest、gbest和群体规模；说明当前实现顺序更新粒子、即时共享gbest。
5. SA邻域、Δf、Metropolis接受概率和降温公式，解释T₀、α、扰动幅度、目标尺度及历史最好值。
6. 公平评价预算、多种子复现、约束与结构应用；术语卡片和参考来源。

SA计算器默认Δf=2、T=5，A=exp(−0.4)≈67.03%。提高温度会增大接受同一较差候选的概率；它不会触发结构求解或修改优化实验设置。切换语言保留两个数值。

## SA交互：候选、接受/拒绝与降温

SA小节新增逐步实验，使用同一Rastrigin函数的y=0截面，以区分当前位置x、候选x′和历史最好x*。可修改当前T、α、候选扰动ε与随机数r；新抽样按钮使用独立的确定性伪随机序列。接受概率由共享的Metropolis函数计算，接受区间条标明A与r的位置。

“热”与“冷”恢复相同x=1、ε=−0.2、r=0.35，分别使用T=10与T=0.5。此候选x′=0.8比x=1差约6.54983分；高温A约51.95%会接受，低温A约0.0002%会拒绝。执行一步应用接受/拒绝，再降温T←αT；表格保存当时的T、f、f′、Δf、A、r、决定及新位置。历史最好仅在改善时更新。

这是手动观察算法机制的一维切片；正式优化器仍为二维随机SA。每步扰动沿用±0.7范围，候选限制在[−5.12,5.12]；温度下限1e−10。30步后需重置。它与原概率计算器、GA/PSO实验和正式优化页的状态相互独立，并在切换语言时保留。

## GA交互：基因来源与变异

GA小节先展示12个固定数学候选及其真实Rastrigin目标值，标出较优6个组成的父代池。选择父代A、B，点击交叉得到C=(A_x,B_y)，再选择变异坐标和ε∈[−1.024,1.024]，点击变异得到C′。蓝/橙颜色及文字标明坐标来源，紫色边框标明变异坐标。右侧比较四个候选的f，图中虚线连接父代与交叉子代，强调子代不保证改善。

这是对既有GA运算的手动拆解：父代由用户选择、变异量由滑块控制，正式算法则随机选择。重置GA不会重置PSO，语言切换保留父代、阶段、坐标和变异量。

## PSO交互：分解并合成移动

初始粒子x=(−3,−2)、v=(0.8,0.4)，示例记忆pbest=(−1,1)、gbest=(1,0)。提供只看惯性/个体学习/群体学习及共同作用预设，或手动调整w/c₁/c₂。三支有色箭头首尾相接，紫色虚线为合成速度，空心圆为下一步位置；虚线方框为[−5.12,5.12]²设计域，视窗随箭头自动缩放。

固定r₁=r₂=0.5以隔离系数的作用。默认合成速度(5.06,4.03)，下一步位置(2.06,2.03)。点击“移动一步”应用截断后的候选，评价Rastrigin并按改善情况更新记忆，记录已走路径；20步后要求重置。保留未经速度上限截断的合成速度，与当前算法边界行为一致。该面板不运行完整群体或结构分析。

公式与固定默认值按 `web/src/algorithms.js` 实现核对。GA不存在唯一更新公式；PSO与SA也存在多种变体，因此明确标注本演示的选择、边界与更新次序。
