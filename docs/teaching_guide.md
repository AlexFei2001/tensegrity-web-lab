# 18 分钟课堂演示

0–3 分钟：打开 Design。讲清三根杆、九根索，转动视角、修改 angle。强调这是原模型的初始几何参数预览，未运行结构求解。恢复 GHX 保存值。

3–6 分钟：进入 Physics。当前附带11条真实GH求解记录，默认上节点位移0.310456 m。用样本下拉框加载170°或197°，比较曲线、输入和变形态。自由拖动到未采样角度时显示 not evaluated。说明静长缩短率 p 与真实预拉力的区别；上节点位移不等于全结构最大位移。质量 null 表示未计算，不是零质量。

6–8 分钟：Comparison 中“一键保存默认 + 角度变化示例”，比较输入与数据状态。可以回到 Design 保存自己的第三个方案。讨论改角度可能改变可行性，但几何看起来稳定不证明物理稳定。

8–13 分钟：Optimization 数学模式。Rastrigin 是已声明的数学函数，不是 Kangaroo 代理。GA、PSO、SA 均用 seed=42、200 次评价。单步观察候选与 best-so-far；暂停、复位，切换算法。复位同种子应重复同一轨迹。改变 PSO w/c1/c2；SA 将温度设100、cooling=.99 可更清楚看到“接受较差解”。真实结构评价次数始终为0。

13–16 分钟：下载 CSV，按评价预算比较，使用 seed=43/44 重复以避免单次随机结果误导。`data/runs/mathematical-comparison.csv` 提供同预算的九次演示运行，不能作为结构算法性能排名。已有 Python 课程实现见仓库 `PSO_GA_python/ga_core.py` 与 `pso_core.py`；浏览器版复用了选择/交叉/变异/精英和速度更新思想，未声称逐位复现 NumPy 的随机序列。

16–18 分钟：回到结构目标 `(−P,u)` 与加权 Fitness。真实数据模式只枚举精确求解且可行的候选。阐明局部最优、Pareto 和权重偏好。没有物理复验数据不展示认证前沿；SA 接受较差目标不意味着允许结构违反约束。

教师控件：右上角切换中文/English/Italiano。第五章节Theory集中讲解GA/PSO/SA的区别、公式和参数，优化页可直达；SA接受概率计算器可辅助解释温度。恢复默认、双方案示例、搜索CSV均可使用。语言切换保留设计、比较、搜索进度与计算器数值。PSO/SA仅显示各自适用参数。手机触屏和WebGL视觉验收因UI服务不可用尚未完成；DOM交互测试已通过。

## 部署

在项目目录运行 `npm install`、`npm run dev`。Node 22.12+，建议沿用 lockfile，重复安装用 `npm ci`。开发服务默认只监听127.0.0.1。

`npm run build` 生成 `web/dist`，可部署到任意静态 HTTP 服务；资源为相对路径，支持子目录。所有 JS、Three.js 和数据打包本地，运行无需 CDN。`npm run preview` 本机检查 production bundle。不要直接双击 index.html，fetch 模型数据需要 HTTP。部署不附带 Rhino 在线计算。
