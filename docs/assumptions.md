# 数据语义与限制

- 原文件、哈希和全部变量共同界定案例；网页不使用最近邻冒充真实求解。
- 空值显示“未提供”，绝不变成 0；零载荷产生的真实零值可保留。
- 预计算记录可以数值已验证但违反位移约束；validated 与 feasible 是不同字段。
- 未求解、非有限、迭代用尽、缺结果必有失败原因；结构安全仍未验证。
- 无匹配记录时，几何从 GHX 生成链移植。11个实测点的3杆/9索端点已与GH导出的原始坐标对齐，误差<1e-9 m。匹配记录的变形态直接使用GH导出坐标。
- 杆/索材料仍待 3mm 多股钢丝绳有效 EA、质量、强度和索只受拉特性校准。浏览器不进行 Kangaroo/Karamba 求解。
- 部署只需静态文件；初次 npm install 需联网，构建后运行无需 CDN。
