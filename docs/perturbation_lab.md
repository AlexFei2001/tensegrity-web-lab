# Grasshopper 小扰动实验

新增组：`小扰动稳定性实验 / Native Kangaroo ±0.1 mm`，在现有画布最右侧。核心脚本为 GhPython，代码完整嵌入 GH 文档，不依赖仓库文件路径运行。安装脚本只添加电池与连线，不更改原目标函数或优化器注册。

## 使用

1. 在原荷载滑块设置 P；保留原来的角度、几何与材料参数。
2. `Amplitude (mm)` 默认 0.1，即正负各 0.0001 m；当前文档必须采用米。
3. `Iteration budget` 默认 300000，为每个独立系统的软迭代预算。
4. `Run test=True`：输入改变后计算；相同输入使用缓存。设为 False 暂停，输入变化后隐藏旧结果，避免将历史结果用于新模型。
5. 查看 `RESULT`：`DECAYED` 表示最终偏移小于初始扰动的 0.2 倍且残差通过检查；`AMPLIFIED` 表示超过 10 倍；中间区域为 `INCONCLUSIVE`，需要更长迭代、较小扰动及刚度判据复查。这两个阈值是实验结果标签，不是数学稳定界限。

## 实际连线与输出

组件从受荷 Zombie 的 `V`、`I` 和原生 cable Spring、strut Spring、Anchor、Unary goal 电池读取数据；五个列表输入均 Flatten。它检查粒子索引、节点数、goal 类型、初始合力残差、索是否拉紧及直线性。

从当前几何的保守弹簧模型计算凝聚切线刚度矩阵（18×18），沿其最小特征值对应模态施加扰动。9 条索各由10段串联弹簧组成，凝聚保留等效刚度与总静长，内节点模态线性插值；这个凝聚只适用于当前拉紧直索。最小特征值的**符号**与全系统稳定性相关，数值不等于完整261×261矩阵的最小特征值。

创建三套新的原生 Kangaroo `PhysicalSystem`：未扰动对照、负扰动、正扰动。每套都从原始 goal 参数重建自己的 Spring/Anchor/Unary，不修改或复用现有求解器的可变 goal。通过原生 `Step` 求解；其批次自适应，可能略超预算，Trace 为三套系统分别记录真实迭代数，不将批次序号当作物理时间。

- `LambdaMin`：凝聚矩阵最小特征值；正值、近零、负值分别提示局部稳定、临界附近、不稳定。临界标签采用 ±1e-6 的数值容差。
- `GainMinus / GainPlus`：最终六个角点相对**原平衡形态**的最大距离 ÷ 扰动幅值。
- `Reference / Initial / Minus / Plus`：原平衡、正向初始扰动、负向终态、正向终态的93段线；可分别打开预览。默认预览 Plus。
- `Chart`：旁置于世界坐标 x=2–4 m 的曲线图，可打开该参数的 Preview。曲线顺序为对照、负扰动、正扰动、gain=1水平线；横轴为各自真实迭代数，纵轴为 log10(gain)。零以下是偏移小于初始幅值。
- `Trace`：CSV文本行，含各系统实际迭代数、绝对增益以及相对移动对照的增益。

失稳时，对照也可能因数值误差离开原平衡，甚至和两个扰动系统落到同一个终态。此时终态彼此接近**不能**解释为回到稳定平衡。因此同时展示对照漂移、相对原平衡的增益和刚度特征值。有限幅值、有限迭代的扰动衰减也不是全局稳定性的证明。

## 本次验证

现场角度已为 **178.453°**，与此前185.748°诊断不同；脚本按当前模型实时读取，不内置旧临界荷载。本次只临时将原荷载改为0.55和0.58以验证，完成后恢复原来的0.543。

| 现场荷载 | 凝聚最小特征值 | 正负扰动终态增益（约） | 结果 |
|---|---:|---:|---|
| 0.55 | +0.008161216 | 0.009537 | 衰减 |
| 0.58 | −0.008806704 | 22970.876 | 放大 |

原生现场运行均无脚本错误；原始记录见 `data/stability/live-canvas-055.json` 与 `live-canvas-058.json`。另用旧185.748°原生样本复验也得到0.55衰减、0.58放大。源 GHX 未覆盖，安装前保存独立快照；包含新增电池的版本另存为 `tensegrity_perturbation_lab.ghx`。

仍有限制：当前仅支持87节点、90索段、3杆的拓扑；不支持松索、弯索、其他 goal 类型。未校准实际力单位，不含杆件弯曲屈曲、材料破坏或真实时间动力学。尚未连接 Opossum；须先明确优化器如何处理计算失败与临界容差。
